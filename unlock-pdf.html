Frequently asked questions

Can this tool crack a password I don't know?

No. This tool does not brute-force, guess, or crack passwords. It requires you to provide the correct password. If you don't know the password, there is no legitimate way to recover it — this is by design of PDF encryption.

What if I only have the owner password (permissions password)?

Owner passwords are accepted. They allow opening the file and removing restrictions like printing or copying. The tool will try your password as both the user password and the owner password.

Does my PDF or password get uploaded anywhere?

No. Everything happens in your browser. Neither the file nor the password leaves your device.

What encryption types are supported?

RC4 (40/128-bit) and AES-256 (PDF 2.0). Certificate-based encryption is not supported.

Why does it say "wrong password" even though I'm sure it's correct?

Possible reasons: the PDF uses a non-standard security handler, the file is corrupted, or the password was changed after you last opened it. Also check for accidental trailing spaces.
