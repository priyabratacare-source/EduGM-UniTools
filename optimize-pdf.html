Frequently asked questions
Does my PDF get uploaded anywhere?

No. Everything runs locally in your browser using PDF.js and pdf-lib. Your PDF never leaves your device.

Which preset should I choose?

Start with Light — it cleans metadata and recompresses streams without touching images, so visual quality is preserved. Use Balanced or Aggressive if you need a smaller file and can accept some image quality loss.

Will image recompression always reduce size?

Usually, but not always. If the original PDF already uses highly compressed images, re-encoding can occasionally increase file size. The tool will still produce a valid PDF — compare the "Original" and "Optimized" sizes before downloading.

What does "linearize" do?

Linearizing (Fast Web View) reorganizes the PDF so the first page can display before the whole file downloads. It's useful for large PDFs on slow connections, but can slightly increase the total file size.

Can I lose form fields or annotations?

Only if you enable "Strip annotations & form fields". By default, interactive elements are preserved. Always test a copy of your PDF first if it contains important forms.

How large can the file be?

Up to about 100 MB. Very large PDFs may take longer because every page and image stream is processed locally.
