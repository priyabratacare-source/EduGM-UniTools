Before you upload

Quick checks to avoid application-form errors.

Important: Exam rules can change each year and may specify file size in KB, pixel dimensions, aspect ratio, background, signature format or a live photograph. Always check the current official information bulletin. These presets are editable suggestions only.

• Keep the face clear and centered for photo uploads.
• Do not crop out required edges of a signature.
• Check both pixel dimensions and KB/MB limits.
• Save the original image before replacing it.

Frequently asked questions

Does this tool upload my photo?

No. Resizing and compression happen in your browser. The page loads its font from Google Fonts, but the selected image is not sent to an EduGM server by this tool.

Are exam presets official?

No. Exam authorities may change requirements by year, post, or application stage. Presets are editable starting points. Verify the current official notification before submitting.

Can I reduce the image file size to a specific KB limit?

Lower JPG/WebP quality and smaller dimensions usually reduce file size, but the final size depends on the image. Check the downloaded file size against the portal's limit. PNG compression may not reduce size as much.

What does crop mode do?

Fill frame crops the edges to fill the chosen dimensions. Fit whole image keeps all of the photo visible and may show a background. Stretch fills the exact dimensions but can distort the image.
