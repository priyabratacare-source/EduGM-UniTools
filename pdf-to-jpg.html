Frequently asked questions

Does my PDF get uploaded anywhere?

No. The entire conversion runs in your browser using PDF.js. The file never leaves your device.

What quality should I choose?

Higher quality (0.95) produces sharper images but larger files. Good (0.90) is a solid balance for most uses. Scale controls the pixel dimensions — 2× is a good default for clear text.

Can I convert only some pages?

Yes — enter a page range like 1-3, 5, 8. Leave blank to convert every page.

Why are my images blurry?

Increase the Render scale to 2.5× or 3× for sharper output. Higher scales also increase file size and processing time.

How large can the file be?

Up to about 50 MB. Very large files with many pages may take longer because each page is rendered sequentially.
