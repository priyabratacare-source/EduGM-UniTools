Frequently asked questions

Does my PDF or password get uploaded anywhere?

No. The PDF is read and encrypted entirely in your browser. Neither the file nor the password ever leaves your device.

What encryption is used?

AES-256 (PDF 2.0, V=5 R=6), implemented using the browser's native Web Crypto API. This is the same encryption standard used by Adobe Acrobat and modern PDF readers [citation:1][citation:2].

What happens if I forget the password?

The password is not stored anywhere. If you lose it, the file cannot be opened — this is intentional. Keep the password safe before sharing the PDF.

Can I remove the password later?

Yes — use the Unlock PDF tool with the password to create an unprotected copy.

Why does encryption need HTTPS?

AES-256 encryption relies on the browser's crypto.subtle API, which is only available in secure contexts (HTTPS or localhost). If this page runs on plain HTTP, encryption will fail — use HTTPS [citation:2][citation:5].

How large can the file be?

Up to about 100 MB. Very large files may take longer to encrypt.
